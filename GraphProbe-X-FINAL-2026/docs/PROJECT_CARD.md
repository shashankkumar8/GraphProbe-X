# GraphProbe-X // Submission Card

**One line:** Adaptive Agentic GraphRAG that earns every extra retrieval step through verified evidence gain.

**Core differentiator:** The controller does not blindly call more agents. It maintains an Evidence Contract + Ledger, classifies the missing evidence, chooses the cheapest useful action, verifies the result, and stops under hard governance.

**Demo moment:** Ask a graph-friendly Olympic question. Show the answer begin with cheap retrieval, then reveal a missing relationship, then the TigerGraph path, then source quote verification, then the stop decision and cost.

**What judges can inspect:** three pipelines, identical evaluation substrate, per-step tool trace, citations, graph provenance, token cost, latency, evidence coverage, and stop reason.

**Research question:** When does additional investigation improve answer quality enough to justify additional retrieval, latency, and token cost?
