# GraphProbe-X — LinkedIn Announcement Post

🚀 Excited to unveil **GraphProbe-X**: an evidence-driven, cost-aware Adaptive Agentic GraphRAG system built on TigerGraph!

RAG retrieves context.
GraphRAG connects relationships.
GraphProbe-X asks a fundamental question:
**"When does additional agentic investigation improve answer quality enough to justify its retrieval, token, and latency cost?"**

Key Innovations:
1️⃣ **Evidence Contract & Ledger:** Every query is parsed into explicit typed requirements, tracking claims against verbatim source text quotes verified in Python.
2️⃣ **Target-Aware Verification:** Prevents wrong-target contamination across temporal and entity boundaries.
3️⃣ **Cost-Aware Governor:** Hard operational limits ensure the agent halts as soon as evidence is sufficient or further search yields diminishing returns.
4️⃣ **TigerGraph Graph Traversal:** 2-hop entity graph paths integrated seamlessly into an adaptive tool loop.

"GraphProbe-X doesn't search harder. It decides whether searching further is justified."
